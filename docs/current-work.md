# Current work

Keep a compact account of the active work so anyone involved can resume it.

## Current focus and status

Identify the intended result of the current piece of work and link to the
relevant agreement and approach. State what is planned, underway, completed or
blocked, and who is responsible where that matters.

## Next actions

Record the next useful actions, dependencies and decisions needed to proceed.
Include how the result will be checked. For work about to be implemented, link
to its agreed [implementation contract](design.md#implementation-contract) and
prepared checks.

## Findings and handover

Distinguish attempted actions, prepared checks and verified results. Link to
the relevant [decisions](decisions.md), checks, changes and
[evidence](../evidence/README.md), including useful failed attempts and known
gaps in the record.

Update this record as work changes. Reuse existing conversations, issues,
activity histories and results for detail. Before pausing or handing over,
retain enough context and references to recover the work without maintaining a
duplicate activity log.

# Project records

Use these records to understand the project, make decisions and continue the
work. Update them when findings change the current understanding.

- [design.md](design.md): the approach, important parts, interactions,
  dependencies and responsibilities.
- [current-work.md](current-work.md): active work, findings, uncertainties,
  dependencies and next actions.
- [decisions.md](decisions.md): important choices, reasons, consequences and
  later changes.
- [delivery.md](delivery.md): usage, acceptance, operation, support and handover.
- [elements/](elements/README.md): detail for parts that need their own records,
  such as a workstream, activity, deliverable or component.

[PROJECT.md](../PROJECT.md) remains the current project agreement. Connect these
records to the relevant explorations, checks, working materials and evidence.
Add detail when it helps contributors; small projects may combine records.

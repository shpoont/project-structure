## v1.0.0 — 2026-10-16

### Added

- General-purpose project guidance for research, creative work, events,
  operations, software and other projects.
- Connected records for the project agreement, design, current work, decisions,
  delivery and parts that need more detail.
- Guidance for working materials, mocks and rehearsals, manual or automated
  tests, and retained evidence.
- Project Execution Model 1.1.0 concepts: implementation contracts, delivery
  acceptance, outcome success, execution constraints, readiness, decision
  authority, completion boundaries and accepted ownership of later checks.
- Versioned release baselines using a changelog and fixed annotated Git tags.

# Models, prototypes and rehearsals

Explore important aspects of the project before committing to the finished
result. Use sketches, storyboards, sample outputs, models, prototypes,
simulations, role plays or rehearsals as appropriate to the work.

For each useful representation, make its purpose, how to use it, relevant
conditions, what it represents, limitations and findings discoverable. Link it
to the [approach](../docs/design.md) and expectations it helps explore. Update the
current project understanding when the exploration changes it.

Be clear about what the exploration demonstrates and what still needs to be
checked in the real setting. Add subfolders for different explorations as needed.

# Working materials

Keep the materials used to produce the project's result here: document drafts,
research analyses, artwork, plans, procedures, data files or software sources.
Arrange them around the actual work, adding meaningful subfolders when needed.

Connect materials to the relevant [approach](../docs/design.md),
[expectations](../PROJECT.md) and checks. Explain how to use or edit them and
identify the current version when alternatives could cause confusion.

Link to material kept in another tool or storage location when practical. Make
required access, tools and any preparation steps discoverable. Identify finished
deliverables and how to use them in [delivery](../docs/delivery.md).
